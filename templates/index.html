Hybrid ML Fraud Detection Architecture
Kaggle Dataset (V1-V28, Time, Amount)
Supervised Model
Random Forest

Trained on labeled Kaggle past fraud transactions to recognize known patterns.

Output: RF Prob (0.00 – 1.00)
Unsupervised Model
Isolation Forest

Isolates anomalies in few tree splits; catches unseen & zero-day novel fraud patterns.

Output: ISO Score (0.00 – 1.00)
Weighted Blend
Combined Risk Score
0.7 × (RF × 100) + 0.3 × (ISO × 100)
Range: 0 – 100
0 – 39: APPROVE

Normal spending pattern. Transaction approved instantly with zero friction.

40 – 69: FLAG & SMS

Suspicious activity. Transaction flagged and instant SMS alert sent to customer.

70+: BLOCK CARD & SMS

Critical fraud threat detected. Card blocked immediately & alert sent to customer + admin.

Seven Functional Project Modules

Fully implemented matching the MCA Mini Project specification

1. Customer Module

Register, login, view card details, execute payments, inspect transaction history, and receive alerts.

2. Bank Admin Module

Monitor live transactions, review fraud alerts, block/unblock cards, and analyze system KPIs.

3. Transaction Processing

Validates card number, expiry, credit limit, and enforces 3+ wrong PIN security lockout.

4. Fraud Detection Module

Passes each swipe to Random Forest + Isolation Forest, yielding 0-100 Risk Score.

5. Alert & Report Module

Stores flagged transactions with rule reasons, manages alert workflows, and exports CSV reports.

6. Chatbot Module

24/7 AI banking support assistant: shows recent transactions, explains flagged rules, and raises block requests.

7. SMS Notification Module (Twilio / Fast2SMS / Mock Gateway)
